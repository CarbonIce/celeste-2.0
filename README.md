# celeste-2.0
Some custom scripts with bits and pieces of the previous celeste CyberPatriot scripts, written for BoilerStorm.

### Usage:
1. Copy all tools to the "Tools" subdirectory
2. Edit DispelMagic line 93 if the Quotient PCR format is not expected and/or uses a different username than the SamAccountName.
3. Run OpeningRounds.ps1
